# Boundary Neural Element Method

Research code, trained operators and compact numerical data for
**“Learning reusable boundary operators as composable numerical elements.”**

The boundary neural element method (BNEM) learns geometry- and
material-conditioned local boundary operators and assembles them through
shared trace degrees of freedom. The released implementation covers
two-dimensional steady heat conduction and small-strain isotropic
plane-strain elasticity.

## Highlights

- Local fine-scale physics is compressed into reusable boundary operators.
- Analytic consistency spaces preserve constant or affine fields exactly.
- Positive-semidefinite complementary operators are generated by compact
  neural Gram factors.
- The same elasticity operator is used for the generalization tests and the
  heterogeneous engineering example.
- In the equal-displacement-accuracy engineering comparison, BNEM reduces the
  global degrees of freedom by 78.1% and 91.7% and achieves 9.44x and 53.15x
  speed-ups in the compressible and nearly incompressible cases, respectively.

## Installation

Create the Conda environment:

```bash
conda env create -f environment.yml
conda activate bnem
```

For an editable Python installation:

```bash
python -m pip install -e .
```

## Quick check

Evaluate the elasticity operator for a distorted quadrilateral:

```bash
python scripts/demo_compact_operator.py
```

Recompute the reported summaries from the packaged numerical records and
verify their expected values:

```bash
python scripts/verify_reported_results.py
python scripts/verify_integrity.py
pytest -q
```

## Generate figure data

Generate panel-ready CSV and JSON data for Figures 2–5:

```bash
python scripts/generate_figure_data.py
```

The output is written to `generated/figure_data/`. It contains the operator
metrics, convergence and ablation tables, equal-accuracy timing records,
load-response curves, representative field samples and mesh geometry. No
plotting program is included; the exported files can be read directly by
Python, R, MATLAB or other visualization software.

## Training

The published elasticity checkpoint uses 1,000 quadrilateral geometries and
ten Poisson ratios from 0.20 to 0.49. Its network has 22 inputs, two hidden
layers of width 48, SiLU activations and three outputs defining a 2 x 2
Cholesky factor.

```bash
python scripts/train_elasticity.py --device cuda
python scripts/train_heat.py --device cuda
```

The complete 1,500-sample parameter hold-out and independent 512-sample mesh
hold-out are released with a Poisson-ratio column. Figure 2 compares the 900
parameter hold-out samples in the common 0.20--0.40 range with all 512
independent-mesh samples. `scripts/generate_figure_data.py` writes this matched
selection to `generated/figure_data/figure2/display_metrics.csv`.

## Data scope

The repository includes the released training arrays, trained checkpoints,
all numerical tables used to verify the reported statistics, representative
field samples and compact mesh geometry. Multi-gigabyte converged FEM reference
meshes and full-resolution solution archives are not stored in Git; their
convergence criteria, hashes and derived numerical records are retained in the
compact release data.

No file in this release exceeds GitHub's 100 MB per-file limit.
